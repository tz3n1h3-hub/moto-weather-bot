# 🏍️ MotoWeather — Telegram-бот погоды для мотоциклистов Минска

Погодный ориентир для райдеров Минска. Не точный прогноз, а честная сводка: **ехать сегодня или нет**.

## Что делает

- Собирает погоду с **4 источников**: METAR (UMMS), Open-Meteo, wttr.in, OpenWeatherMap
- Убирает выбросы, показывает **среднее значение** по живым источникам
- Считает **риск 0–10** по 6 параметрам: ветер, осадки, видимость, температура, влажность, время суток
- Выдаёт **вердикт**: «ДОРОГА ЧИСТАЯ — ГАЗУЙ» / «ЕХАТЬ МОЖНО» / ... / «НЕ ВЫЕЗЖАЙ»
- **Утренняя рассылка** в 7:00 Минск для подписчиков
- Прогноз на **ближайший период** + на **завтра**

## Стек

- Python 3.14 (или 3.11+)
- pyTelegramBotAPI 4.24.0
- Flask 3.0.3
- Upstash Redis (REST)
- Render.com (free tier, Frankfurt)

## Команды

- `/start` — о проекте + «ПРОГНОЗ»
- `/weather` — погода
- `/about` — о проекте + подписка
- `/subscribe`, `/unsubscribe`
- `/stats` — админ
