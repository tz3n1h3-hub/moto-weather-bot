# 🏍️ MotoWeather — Telegram-бот погоды для райдеров Минска

Погодный ориентир для райдеров Минска. Не точный прогноз, а честная сводка: **ехать сегодня или нет**.

**Версия:** v1.8.3 (26.09.2026)

## Что делает

- Собирает погоду с **4 источников**: METAR (UMMS), Open-Meteo (5 точек Минска), wttr.in, OpenWeatherMap
- **Многоточечный прогноз** по районам: Центр, Север (Уручье), Юг (Малиновка), Запад (Каменная Горка), Восток (Шабаны)
- Убирает выбросы (σ-фильтр), показывает среднее по живым источникам
- **Голосование по дождю** с весами: METAR=2, OM=2, OWM=1.5, wttr=1 (порог 3.0). Морось учитывается с множителем 0.25 — «морось ≠ дождь»
- **Видимость** — минимум из источников, но с проверкой разброса (если METAR даёт 2 км, а город 10+ — показывает среднее с пометкой «в аэропорту 2 км»)
- Считает **риск 0–10** по параметрам: град, ветер, осадки, видимость, туман/мокрая дорога, изморозь, температура, почва, ночь
- Выдаёт **вердикт**: «ДОРОГА ЧИСТАЯ — ГАЗУЙ» / «ЕХАТЬ МОЖНО» / ... / «НЕ ВЫЕЗЖАЙ»
- **Астрономические периоды** по Солнцу: НОЧЬ / РАССВЕТ / УТРО / ДЕНЬ / ВЕЧЕР
- **Утренняя рассылка** в 7:00 Минск для подписчиков
- Прогноз на **ближайший период** + **завтра**

## Блоки сообщения

Сообщение разбито на блоки для удобства навигации и жалоб:

- 【A】Шапка
- 【B】Вердикт СЕЙЧАС
- 【C】ЧТО НА ДОРОГЕ
- 【D】НА СЕБЯ
- 【E】ПЕРЕД ВЫЕЗДОМ
- 【F】ТЕКУЩАЯ ПОГОДА
- 【F2】ОСАДКИ ПО РАЙОНАМ *(показывается, только если где-то ≥ 0.3 мм)*
- 【G】Ближайший период
- 【H】ЗАВТРА
- 【I】Источники
- 【J】Совет

## Фидбэк-система

Кнопка «❗️ ЧТО-ТО НЕ ТАК?» после прогноза. Райдер выбирает:
1. **Блок** (【A】–【K】)
2. **Параметр** (видимость / ветер / осадки / температура / дорога / туман / другое)
3. **Направление** (меньше / больше / не показано / другое)
4. **Комментарий** — опционально

Сохраняется в Redis на 30 дней. Админ-команды:
- `/feedback` — сводка за 7 дней (топ блоков и параметров + последние 5)
- `/feedback_detail <user_id>` — детали последней жалобы

Анти-спам: 1 жалоба в час на райдера.

## Стек

- Python 3.14 (или 3.11+)
- pyTelegramBotAPI 4.24.0
- Flask 3.0.3
- Upstash Redis (REST API)
- Render.com (free tier, Frankfurt)
- Cloudflare Worker — прокси для Open-Meteo (обход 429)
- UptimeRobot — keep-alive пинг `/health` каждые 5 мин

## Команды

- `/start` — о проекте + кнопка «ПРОГНОЗ»
- `/weather` — погода
- `/about` — о проекте + подписки
- `/subscribe` — подписка на утро
- `/unsubscribe` — отписка
- `/updates` — переключение уведомлений об обновлениях
- `/stats` — админ: статистика + changelog
- `/feedback` — админ: сводка фидбэка за 7 дней
- `/feedback_detail <user_id>` — админ: детали

## Flask endpoints

- `GET /` — «🏍️ MotoWeather Bot is running!» (200)
- `GET /health` — JSON со статусом, версией, счётчиками (200)
- `GET /favicon.ico` — 204
- `GET /apple-touch-icon-precomposed.png` — 204
- `GET /cron/morning?secret=XXX` — ручной триггер рассылки
- `GET /cron/version?secret=XXX` — ручной триггер уведомления о версии

## Redis-ключи

- `users` — set всех райдеров
- `subscribers` — set подписчиков на утро
- `updaters` — set подписчиков на обновления
- `om_cache_v2` — JSON от OM (TTL 30 мин свежий + 2 часа stale)
- `om_multi_cache` — 5 точек Минска (TTL 10 мин)
- `soil_temp:MINSK` — температура почвы (TTL 24 часа)
- `last_morning_date` — дата последней рассылки
- `last_notified_version` — последняя уведомлённая версия
- `last_msg:{chat_id}` — ID последнего сообщения бота
- `feedback:*` — жалобы (TTL 30 дней)
